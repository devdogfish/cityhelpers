# City Helpers team notes

Website: https://devdogfish.github.io/cityhelpers/

Published by GitHub Pages from the root of the `main` branch using Jekyll. Only the curated Markdown notes are copied into this repository.

The original project notes live one directory above this checkout. To publish updates after editing those notes:

```sh
python3 sync-notes.py
git add objective.md target-audience.md context.md
git commit -m "Update project notes"
git push
```

You can also edit the Markdown pages directly on GitHub; the next local sync replaces those copies with the original project notes.
